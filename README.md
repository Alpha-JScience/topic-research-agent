# 🔬 Topic Research Agent

Instant, multi-format research briefs on any topic — from AI to Art History.

## 🚀 Features
- **Smart Classification:** Auto-detects if a topic is "IT/AI" or "General" and tailors the prompt accordingly (with manual override).
- **Flexible Output:** Choose from 8 distinct output formats (Paragraph, Bullet, Fact Table, Quick Summary, Practical Example, Quiz MCQ-4, Q&A, Default).
- **Adjustable Depth:** 6 depth levels (General, Medium, Detailing, Conceptual, Theoretical, Paragraphical).
- **Powered by DeepSeek:** Uses DeepSeek API via OpenAI-compatible SDK for fast, cost-effective inference.
- **Reloadable Knowledge Base:** Update `topics.csv` on the fly via the UI sidebar without restarting the app.
